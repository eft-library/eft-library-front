# 라이브 맵 사용 가이드

이 문서는 현재 EFT Library 라이브 맵에 구현된 기능과 사용 방법을 설명합니다.

## 1. 기본 화면 구성

라이브 맵은 크게 네 부분으로 구성됩니다.

- 상단: 내 위치 찾기 입력창 및 프로그램 안내
- 왼쪽 패널: 지도·층 선택과 각종 위치 및 스폰 필터
- 중앙: 실제 지도와 마커
- 오른쪽 패널: 퀘스트·스토리·이벤트 목록 및 상세정보

왼쪽과 오른쪽 패널은 각각 접거나 펼칠 수 있습니다.

오른쪽 패널의 열림·닫힘 상태는 모든 지도에서 공통으로 유지되며, 새로고침 후에도 유지됩니다. 왼쪽 패널은 페이지에 들어올 때 기본적으로 열린 상태로 시작합니다.

## 2. 지도 기본 조작

### 지도 이동

마우스 왼쪽 버튼으로 지도를 드래그하여 이동할 수 있습니다.

빠르게 드래그하거나 마우스가 지도 밖으로 벗어나더라도 브라우저의 텍스트나 UI가 선택되지 않도록 처리되어 있습니다.

### 확대·축소

다음 방법으로 지도를 확대하거나 축소할 수 있습니다.

- 지도 왼쪽 위의 `+`, `-` 버튼
- 마우스 휠
- 터치패드 스크롤

지도에서 더블클릭 확대는 비활성화되어 있습니다. 마커를 빠르게 클릭하거나 지도를 드래그할 때 의도하지 않게 확대되는 것을 방지하기 위한 동작입니다.

확대·축소 중에는 일부 마커 이름표가 잠시 숨겨질 수 있습니다. 확대·축소가 끝나면 다시 표시됩니다.

### 층 전환

층은 왼쪽 패널의 층 목록에서 선택할 수 있습니다.

또한 지도 위에서 다음 단축 조작을 사용할 수 있습니다.

- `Alt + 휠 위`: 이전 층
- `Alt + 휠 아래`: 다음 층

휠을 아래로 내리면 층 목록상 아래쪽 층으로 이동합니다.

층이 변경되면 기존에 선택되어 있던 마커 포커스는 해제됩니다.

### 첫 진입 층

지도에 처음 진입하면 다음 순서로 기본 층을 선택합니다.

1. `is_main`으로 지정된 층
2. `floor_no`가 1인 층
3. 위 조건이 없으면 API에서 가장 먼저 전달된 층

층 목록 순서는 서버에서 전달되는 순서를 그대로 사용합니다.

### 다른 층 표시

선택한 층은 선명하게 표시되고, 다른 층 지도는 반투명하게 표시될 수 있습니다. 여러 층의 구조 관계를 대략적으로 파악하기 위한 기능입니다.

## 3. 지도 회전

지도 오른쪽 위의 회전 버튼을 누르면 지도가 시계 방향으로 90도씩 회전합니다.

지원되는 각도는 다음과 같습니다.

- 0도
- 90도
- 180도
- 270도

회전 시 짧은 애니메이션이 적용됩니다. 운영체제에서 애니메이션 줄이기 설정을 사용 중이면 애니메이션이 생략될 수 있습니다.

회전은 단순히 배경 이미지만 돌리는 방식이 아닙니다. 다음 항목에도 모두 회전 보정이 적용됩니다.

- 일반 마커
- 퀘스트·스토리·이벤트 마커
- 사용자 현재 위치
- 사용자가 바라보는 방향
- 좌표 변환
- 지도 위에 그린 그림
- 마커 포커스 및 지도 이동 위치

회전 값은 지도마다 별도로 저장됩니다. 예를 들어 세관은 90도, 인터체인지는 180도로 설정할 수 있으며 새로고침 후에도 각각 유지됩니다.

## 4. 내 위치 찾기

### 직접 입력 방식

상단 입력창에 다음 정보를 입력할 수 있습니다.

- 게임 좌표
- Escape from Tarkov 스크린샷 파일명

입력 후 `Locate` 버튼을 누르거나 Enter를 누르면 위치가 표시됩니다.

스크린샷 파일명을 입력창에 붙여넣으면 붙여넣은 내용을 즉시 분석합니다. 이후 `Locate` 버튼으로 다시 적용할 수도 있습니다.

파일명에 포함된 위치 좌표와 회전값을 분석하여 다음 내용을 표시합니다.

- 현재 X/Z 위치
- 사용자 위치 마커
- 사용자가 바라보는 방향
- 좌표에 해당하는 층

### 층 자동 판정

현재 위치를 찾으면 높이와 지도 구역 정보를 사용해 적절한 층으로 자동 전환합니다.

층 판정은 다음 순서로 진행됩니다.

1. 특정 좌표 구역에 지정된 층 정보
2. 층별 최소·최대 높이
3. 높이 제한이 없는 기본 층
4. 찾지 못하면 첫 번째 층

복잡한 지하·실내 구조가 있는 지도에서는 단순 높이뿐 아니라 좌표 구역 정보도 함께 사용합니다.

### 자동 위치 연동 프로그램

`프로그램 다운로드` 버튼을 누르면 내 위치 찾기 안내창이 열립니다.

자동 위치 연동 방법은 다음과 같습니다.

1. `where-am-i.exe`를 실행합니다.
2. 이메일을 입력합니다.
3. EFT Library 홈페이지에 로그인합니다.
4. 현재 플레이 중인 지도를 라이브 맵에서 선택합니다.
5. 게임 내에서 스크린샷을 촬영합니다.
6. 위치가 자동으로 지도에 표시됩니다.

자동 연동은 로그인 상태와 프로그램 연결이 필요합니다.

### 프로그램 없이 사용

프로그램을 사용하지 않아도 다음 방법으로 위치를 찾을 수 있습니다.

1. 게임 안에서 스크린샷을 촬영합니다.
2. 생성된 스크린샷 파일명을 복사합니다.
3. 라이브 맵 입력창에 붙여넣습니다.
4. `Locate` 버튼을 누릅니다.

반드시 게임 내 스크린샷 기능을 사용해야 합니다.

다음 방식으로 촬영한 이미지는 좌표 정보가 없어서 사용할 수 없습니다.

- Windows 캡처 도구
- Steam 자체 스크린샷
- 일반 화면 캡처 프로그램

기본 게임 스크린샷 키는 `Print Screen`입니다. Steam 버전에서 게임 내 스크린샷이 생성되지 않으면 게임 키 설정에서 스크린샷 기능을 사용하지 않는 다른 키로 지정해야 합니다.

### 자동 이동 잠금

보기 설정에서 `자동 이동 잠금`을 켜면 새로운 현재 위치가 수신되어도 지도가 강제로 해당 위치로 이동하지 않습니다.

현재 위치 마커 자체는 갱신되지만, 사용자가 보고 있던 지도 화면은 유지됩니다.

이 설정은 현재 위치 자동 추적에만 적용됩니다. 오른쪽 상세 패널에서 목표 위치를 직접 클릭한 경우에는 해당 위치로 이동합니다.

## 5. 왼쪽 위치·스폰 패널

왼쪽 패널에서는 지도와 층을 선택하고, 지도에 표시할 위치 마커를 관리할 수 있습니다.

현재 제공되는 주요 위치 유형은 다음과 같습니다.

- 탈출구
- 트랜짓
- 트랜짓 스위치
- 열쇠 스폰
- 키카드 스폰
- 잠긴 문
- 잠긴 컨테이너
- 고정 무기
- BTR 정류장
- PMC 스폰
- SCAV 스폰
- 저격 스캐브 스폰
- 보스 스폰
- 군즈 스폰
- 컬티스트 스폰
- 레이더 스폰
- 로그 스폰
- 블랙 디비전 스폰
- 기타 서버에서 제공되는 위치 유형

서버에서 `is_use=true`로 전달된 위치만 표시됩니다.

### 카테고리 접기·펼치기

위치 카테고리는 지도에 처음 진입했을 때 모두 접힌 상태로 시작합니다.

상단의 다음 버튼을 사용할 수 있습니다.

- 전체 펼치기
- 전체 접기

각 카테고리를 개별적으로 펼치거나 접을 수도 있습니다.

일부 단순 스폰 카테고리는 개별 위치 목록 대신 카테고리 단위로만 관리될 수 있습니다.

### 위치 표시 ON/OFF

다음 단위로 마커를 켜거나 끌 수 있습니다.

- 전체 위치
- 카테고리 전체
- 개별 위치
- 탈출구 진영별

탈출구는 다음 기준으로도 구분됩니다.

- PMC
- Scav
- 공용
- 기타

꺼진 위치는 지도에서 숨겨집니다.

이 설정은 지도별로 저장됩니다. 세관에서 끈 위치가 다른 지도에서도 함께 꺼지는 방식은 아닙니다.

### 위치 검색

검색창에서 위치 이름이나 카테고리명을 검색할 수 있습니다.

검색 중에는 일치하는 카테고리가 자동으로 펼쳐지고, 관련 위치와 마커를 빠르게 찾을 수 있습니다.

### 목록에서 위치 선택

왼쪽 목록의 위치 이름을 클릭하면 다음 동작이 실행됩니다.

- 해당 위치가 있는 층으로 전환
- 해당 마커가 보이도록 지도 이동
- 마커 강조
- 마커 팝업 열기
- 선택된 목록 항목 강조

반면 지도 위의 마커를 직접 클릭할 때는 사용자가 보고 있던 화면이 강제로 이동하지 않습니다.

## 6. 정적 위치 마커 팝업

정적 위치 마커를 클릭하면 이름, 설명, 이미지 등 서버에서 제공하는 정보를 팝업으로 확인할 수 있습니다.

### 이미지 보기

이미지가 여러 장이면 다음 기능을 사용할 수 있습니다.

- 대표 이미지 확인
- 하단 썸네일 선택
- 이미지 개수 확인
- 대표 이미지를 클릭하여 확대 보기

확대 이미지는 브라우저 화면 크기에 맞춰 제한되며, 좁은 화면에서는 더 작게 표시됩니다.

### 열쇠·키카드 상세 페이지

열쇠, 키카드, 잠긴 문, 잠긴 컨테이너에 연결된 아이템 정보가 있으면 아이템 상세 페이지를 새 창으로 열 수 있습니다.

`normalized_name` 정보가 있는 아이템만 상세 페이지 연결이 표시됩니다.

### 보스 및 부하 정보

다음 스폰 유형은 보스·부하 정보를 팝업에서 확인할 수 있습니다.

- 보스
- 블랙 디비전
- 컬티스트
- 군즈
- 레이더
- 로그

제공되는 정보는 데이터가 있는 경우 다음과 같습니다.

- 대장 이름
- 대장 사진
- 대장 등장 확률
- 현재 위치 선택 확률
- 부하 이름
- 부하 사진
- 부하 수
- 부하 수별 확률

`등장 확률`은 해당 그룹의 등장 확률이며, `현재 위치 확률`은 여러 스폰 지점 중 현재 지점이 선택될 가능성을 나타냅니다.

부하의 개수와 확률은 서로 구분되는 색상으로 표시됩니다.

## 7. 오른쪽 퀘스트·스토리·이벤트 목록

오른쪽 패널에는 다음 세 가지 목록이 있습니다.

- 퀘스트
- 스토리
- 이벤트

각 항목은 독립적으로 접고 펼칠 수 있습니다.

상단의 `전체 펼치기` 또는 `전체 접기`를 사용하면 세 목록을 한 번에 정리할 수 있습니다.

### 목록별 기능

각 목록에서는 다음 기능을 사용할 수 있습니다.

- 검색
- 전체 마커 ON/OFF
- 개별 마커 ON/OFF
- 표시 중인 항목 수 확인
- 항목 선택
- 선택 항목 강조

검색어를 입력하면 목록과 지도 마커가 함께 좁혀집니다.

### 목록 정렬

퀘스트 목록은 프론트에서 다시 정렬하지 않고 서버에서 전달된 순서를 그대로 사용합니다.

따라서 한글 우선, 영문 후순위 정렬이 필요한 경우 API 응답 순서가 그대로 반영됩니다.

### 선택 항목 강조

오른쪽에서 퀘스트·스토리·이벤트 이름을 클릭하면 관련된 지도 마커가 강조됩니다.

같은 항목에 위치가 여러 개라면 모든 관련 마커가 함께 강조됩니다.

다른 마커를 반투명하게 만들지는 않고, 선택한 마커에 반복 강조 애니메이션만 적용됩니다.

강조 애니메이션은 항목 선택을 해제하거나 다른 항목을 선택할 때까지 유지됩니다. 운영체제의 애니메이션 줄이기 설정이 켜져 있으면 정적인 강조로 보일 수 있습니다.

### 다른 층의 목표

목표가 현재 층과 다른 층에 있으면 목표 위치에 층 이름이 텍스트로 표시됩니다.

목표 위치를 클릭하면 해당 층으로 자동 전환되고, 정확한 마커 위치로 이동합니다.

### 다른 지도의 이벤트

이벤트 목록은 현재 지도 이벤트만 보여주는 것이 아니라 전체 지도의 이벤트를 보여줍니다.

다른 지도 이벤트에는 지도명 배지가 표시됩니다.

다른 지도에 있는 이벤트 목표를 클릭하면 해당 지도 라이브 맵으로 이동한 뒤 목표 마커를 엽니다.

실제 지도 위에 표시되는 이벤트 마커는 현재 지도에 속한 마커만 표시됩니다.

## 8. 퀘스트 진행 상태

퀘스트 목록 왼쪽의 원형 버튼은 마커 표시 버튼이 아니라 퀘스트 완료 상태를 변경하는 버튼입니다.

오른쪽의 스위치가 지도 마커 표시 ON/OFF입니다.

퀘스트 완료 처리를 하면 다음 동작이 적용됩니다.

- 퀘스트 로드맵에 완료 상태 저장
- 해당 퀘스트 마커 숨김
- 상세 패널에 완료 상태 표시

퀘스트 진행 상태 저장은 로그인이 필요합니다.

로그인하지 않은 상태에서 완료 상태를 변경하면 `로그인이 필요합니다.` 안내가 표시됩니다.

카파 필수 퀘스트에는 별도의 카파 표시가 나타납니다.

## 9. 상세정보 패널

퀘스트·스토리·이벤트를 선택하면 오른쪽에 상세정보 패널이 열립니다.

상세정보는 선택할 때 API에서 불러오며, 이미 불러온 정보는 화면 안에서 재사용됩니다.

### 퀘스트 상세정보

다음 정보가 표시될 수 있습니다.

- 퀘스트 이름
- 상인 이름과 이미지
- 카파 필수 여부
- 진행 중·완료 상태
- 최소 요구 레벨
- 퀘스트 목표
- 목표별 필요 수량
- 목표 위치
- 목표가 있는 층
- 필요 아이템
- 필요 열쇠
- 경험치 보상
- 상인 평판
- 스킬 보상
- 보상 아이템
- 상점 해금
- 제작 해금
- 선행 퀘스트
- 다음 퀘스트

`상세 페이지` 버튼을 누르면 전체 퀘스트 상세 페이지가 새 창으로 열립니다.

필요 아이템이나 열쇠를 클릭하면 해당 아이템 상세 페이지가 새 창으로 열립니다.

항목이 많을 경우 `더 보기`와 `접기`를 사용할 수 있습니다.

### 스토리 상세정보

다음 내용이 표시될 수 있습니다.

- 스토리 제목
- 선행 조건
- 필요 아이템
- 목표
- 하위 목표
- 목표 위치
- 목표별 보상
- 관련 상세 페이지

### 이벤트 상세정보

다음 내용이 표시될 수 있습니다.

- 이벤트 이름
- 이벤트 목표
- 하위 목표
- 필요 아이템
- 지도별 목표 위치

### 목표 위치 클릭

상세 패널에서 목표 또는 위치 버튼을 클릭하면 다음 동작이 실행됩니다.

- 해당 지도로 이동
- 해당 층으로 전환
- 정확한 위치로 지도 이동
- 관련 마커 강조
- 마커 팝업 열기
- 선택된 목표가 상세 패널 안에서 보이도록 스크롤

지도 위 마커를 직접 클릭할 때는 화면을 강제로 이동하지 않지만, 상세 패널에서 목표를 클릭할 때는 위치 확인이 목적이므로 화면 이동이 유지됩니다.

## 10. 마커 팝업 동작

### 팝업 열기

지도 마커를 클릭하면 마커 팝업이 열립니다.

퀘스트·스토리·이벤트 마커는 보기 설정에 따라 오른쪽 상세정보 패널도 함께 열릴 수 있습니다.

### 팝업 닫기

팝업은 다음 방법으로 닫을 수 있습니다.

- 팝업 오른쪽 위 `X`
- `ESC`
- 다른 마커 또는 다른 목록 항목 선택

팝업을 닫으면 URL의 마커 포커스 정보도 제거됩니다.

상세 패널과 마커 팝업이 함께 열린 경우 ESC를 누르면 마커 팝업이 먼저 닫히고 상세 패널은 유지됩니다. 이후 다시 ESC를 누르면 상세 패널을 닫을 수 있습니다.

팝업을 ESC로 닫은 후 지도를 드래그해도 닫힌 팝업이 다시 나타나지 않도록 처리되어 있습니다.

### 다른 항목 선택

마커 팝업이 열린 상태에서 오른쪽 목록의 다른 퀘스트·스토리·이벤트를 선택하면 기존 팝업은 닫히고 새 항목으로 전환됩니다.

## 11. 보기 설정

보기 설정은 지도 오른쪽 위에서 열 수 있습니다.

보기 설정에 있는 항목은 모두 전체 지도에서 공통으로 사용되며 새로고침 후에도 유지됩니다.

### 차분한 모드

지도와 마커의 색감을 조금 더 차분하게 표시합니다.

기본 정보나 마커 개수는 바뀌지 않고 시각적인 색감만 변경됩니다.

### 간편 표시·상세 표시

마커의 시각적 표현을 간소화하거나 상세하게 표시합니다.

마커 데이터나 필터 상태는 바뀌지 않습니다.

### 이름 표시·숨김

보스, 탈출구 등 정적 위치 마커의 이름표를 표시하거나 숨깁니다.

마커 자체는 유지되고 텍스트 이름표만 변경됩니다.

### 자동 이동 잠금

자동 위치 연동으로 새 위치가 들어올 때 지도가 자동으로 이동하는 것을 허용하거나 잠급니다.

### 마커 선택 시 상세정보 표시

퀘스트·스토리·이벤트 마커를 클릭했을 때 오른쪽 상세 패널까지 함께 엽니다.

### 마커 선택 시 위치만 표시

퀘스트·스토리·이벤트 마커를 클릭해도 오른쪽 상세 패널을 열지 않고 다음 내용만 표시합니다.

- 마커 팝업
- 관련 마커 강조
- 선택 위치 표시

이 설정을 사용하더라도 오른쪽 목록에서 이름이나 목표를 직접 클릭하면 상세정보 패널을 열 수 있습니다.

## 12. 지도 그리기

지도 오른쪽 위의 그리기 버튼을 누르면 그리기 도구가 열립니다.

### 도구 종류

- 손 도구: 지도 이동
- 빨간 펜
- 파란 펜
- 지우개
- 마지막 작업 취소
- 현재 층 그림 전체 삭제

펜이나 지우개를 선택하면 지도 드래그 대신 그리기 동작이 실행됩니다. 다시 지도를 이동하려면 손 도구를 선택해야 합니다.

### 층별 그림 관리

그림은 현재 지도와 현재 층을 기준으로 따로 관리됩니다.

다른 층으로 이동했다가 돌아오면 해당 층에 그렸던 그림이 다시 표시됩니다.

`마지막 작업 취소`는 현재 층에서 마지막으로 그린 선을 제거합니다.

`그림 전체 삭제`는 현재 지도와 현재 층의 그림만 삭제합니다. 삭제 전 전용 확인 팝업이 표시됩니다.

확인 팝업은 다음 방법으로 닫을 수 있습니다.

- 취소 버튼
- 팝업 바깥쪽 클릭
- ESC

그림은 서버나 브라우저 저장소에 영구 저장되지 않습니다. 새로고침하거나 다른 지도 페이지로 이동하면 그림이 사라질 수 있습니다.

## 13. 좁은 화면·세로 모니터 대응

브라우저의 전체 화면 폭을 기준으로 팝업과 패널 크기가 조절됩니다.

화면 폭이 좁아지면 다음과 같이 변경됩니다.

- 마커 팝업 너비와 이미지 크기 축소
- 오른쪽 패널 너비 축소
- 퀘스트 목록과 상세정보를 세로로 분할
- 상세정보 패널과 목록 패널을 동시에 확인할 수 있도록 높이 조정
- 일부 버튼의 텍스트를 숨기고 아이콘 위주로 표시
- 지도 사용 영역을 최대한 확보

큰 화면에서는 목록과 상세 패널이 좌우로 나란히 표시될 수 있습니다.

## 15. 로그인 없이 사용할 수 있는 기능

다음 기능은 로그인하지 않아도 사용할 수 있습니다.

- 지도 열람
- 지도 이동 및 확대·축소
- 층 전환
- `Alt + 휠` 층 전환
- 지도 회전
- 마커 필터
- 위치 및 스폰 검색
- 퀘스트·스토리·이벤트 정보 확인
- 수동 좌표 및 스크린샷 파일명으로 위치 찾기
- 지도 그리기
- 보기 설정

다음 기능은 로그인이 필요합니다.

- 자동 위치 연동 프로그램 사용
- 퀘스트 완료 상태 및 로드맵 저장
